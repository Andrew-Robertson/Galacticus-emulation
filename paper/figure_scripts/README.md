# Paper Figure Scripts

These scripts are manuscript-specific figure and table builders. Reusable
emulator workflow entry points remain in the repository-level `scripts/`
directory.

Run these commands from the repository root unless a script says otherwise.
Most scripts need the full campaign products that will live in the Zenodo data
archive; compact derived inputs are mirrored in `paper/figure_data/` where that
is practical.

## Scripts

- `render_smf_z0_cached_cv_paper_figures.py` renders paper-style SMF z~0
  validation figures from cached campaign cross-validation products.
- `plot_fig4_combining_constraints.py` is the command wrapper for the
  standard-observable constraint-combination figure.
- `plot_standard_corner_observable_composite.py` builds the composite
  posterior-corner plus observable-panel figure used by the wrapper above.
- `plot_standard_observable_posterior_band_overlay.py` builds posterior
  observable-band overlays for standard observables.
- `plot_final_map_validation_paper_figures.py` builds the final MAP validation
  panels, including direct Galacticus/N-body comparisons when the archived
  HDF5 products are available.
- `generate_final_calibrated_parameters_table.py` generates the calibrated
  parameter table from the final MCMC HDF5 results.

## Data Boundaries

The checked-in `paper/figure_data/` files are intended for inspection,
lightweight replotting, and provenance. They are not a replacement for the
Zenodo data release: scripts that evaluate posterior samples or read direct
Galacticus outputs still require the archived emulator bundles, MCMC HDF5
files, and Galacticus HDF5 outputs.

The SMF z~0 PCA-threshold cross-validation data in
`paper/figure_data/smf_z0_cv/` were generated by the reusable validation script
`scripts/run_smf_z0_pca_threshold_cv.py`, which remains in the top-level
`scripts/` directory.
